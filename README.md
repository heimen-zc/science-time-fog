# 答案诞生之前

一个从现代出发、穿过“时间迷雾”重做关键科学实验的互动科普 Demo。

当前主线任务是法拉第 1831 年电磁感应实验。玩家从可以亲手操作的装置开始，观察异常、保存零结果、只改变一个条件做对照；随后带着真实记录进入“证据密室”，通过回放、拆解解释和剪接胶片完成科学质询，最后打开历史档案箱。

## 新版：证据密室与研究手记

后半段默认不再使用长实验列表和选择题法庭。三关分别采用不同操作：

1. **同步放映**：把只改变电池方向的两卷胶片拖进 A、B 回放机，转动同步时间光标，定格指针反向的瞬间。改变动作、铁芯、匝数等混杂条件会得到具体说明。
2. **拆解解释**：移开“漏电说”所依赖的电池，装入实际完成的无电池磁铁运动记录，找到仍有响应的一帧。
3. **剪接影片**：将同一次操作中的靠近、近处停住、远离接成影片，定格“磁铁仍在、指针归零”的零结果。远处的零不能代替这份证据。

每关一条当前指引，三级提示，拖放和点选放入两种等价操作；时间光标支持键盘。获得三枚方法印章后，松开黄铜锁扣、打开研究手记，逐页翻阅六个真实历史节点。每页可掀开“支持什么 / 还不能证明什么”的批注，为检查过边界的来源盖章，并在科学护照中查看。原始日记、藏品、手稿和报告链接仍可直接访问；不以点击外链作为通关条件。

真实实验本及经复核的密室印章仅保存在本机，刷新后可继续；最多保留 24 条记录，优先保留已验证结论所需的证据、完整对照与三时刻，再保留近期尝试。回放和预演均不新增实验、不自动下结论。手记的阅读印章仅保留在当前打开期间。返回地图可继续已有证据；“重新实验”或重置会开始新实验本。旧版自由实验室仍保留为进阶入口。

- `?lab=inquiry`：打开自己的证据密室，缺少记录时明确引导回实验台补齐，不伪造证据。
- `?lab=inquiry&preview=1`：明确标记的教学样例预演，与真实实验、印章和 XP 隔离。
- 判定与回放共用 `lib/inquiry-game.ts`；磁铁胶片插值读取实际保存的轨迹与指针数据，感应环按保存条件重建无量纲慢放模型，两者均明确标为教学回放而非实物录像。

### 氛围插画来源

`public/evidence-room.webp` 使用内置 `image_gen` 生成后转为 WebP，作为两间房间的氛围背景，不是历史照片或装置复原证据。仪器、指针、胶片、书匣与手记交互均由 HTML/CSS/SVG 控制，不需要图像或视频 API 密钥。

生成提示（内容规格）：为面向 9 岁以上的科学侦探历险设计一间十九世纪伦敦雨夜实验室；手绘冒险游戏风格，略俯视的宽幅正面构图，中间约六成留作空净的胡桃木实验桌。左侧雨痕拱窗与冷青月光，桌边暖色油灯、铜线轴和黄铜罗盘；右侧深木色标本抽屉、玻璃器皿、黄铜包边档案箱。海军蓝、低饱和青绿、古金与暖纸色，细腻木工纹理、空间层次与微尘。无人物、怪物、界面、文字、伪手稿、标志、现代设备、霓虹和水印。氛围插画而非真实档案；横向宽幅构图。

最终校正提示：仅将窗外尚未存在于 1831 年的可辨认钟楼改为普通的十九世纪早期屋顶、烟囱与远处无钟教堂尖顶；保留月亮、雨窗、实验室内所有物件、构图、留白桌面、光线、青金配色、手绘风格和画幅。无文字、水印；仍是虚构游戏氛围图，不作为档案复原。

## 直接操作的动画实验

首页可直接进入“只动一下的指针”。首屏只突出一个可操作节点：合上开关，观察指针回零，再抬起开关。完成观察后，拖动或依次点击两张记录叠放曲线；再只反转电池，做一组其他条件不变的对照。

仪器在完整观察窗口结束后保存记录。示范、暂停、慢放及原理回放均不产生额外证据；收齐六条观察后才解锁现代磁场示意。完成后直接进入可拖动的磁铁与线圈实验，之后一起接入实验日志、科学质询和历史档案。

- 装置是可以直接响应点击、拖动和键盘操作的 HTML/SVG 动画。
- 手机支持点击代替拖动，操作热点保持足够大小。
- 一套纯模型同时驱动磁通量、感应电动势、指针和记录；模型保留 `e = -dΦ/dt` 的关系，但使用无量纲相对刻度并放慢瞬态，不用于定量测量。
- 只在用户操作后运行实验；离开屏幕或隐藏标签页时暂停，支持减少动态效果的系统设置。
- 可用 `?lab=induction` 直接打开本关。

科学模型位于 `lib/induction-model.ts`，交互场景位于 `components/induction-discovery.tsx`。插画从 `scripts/induction-art/build.mjs` 生成并进行几何检查，前端只读取预计算的矢量路径。绘图工具沿用 Anatomy 的 MIT 授权代码。

## 第二场发现：磁铁不碰线圈

直接拖动磁铁或它的滑座，沿导轨完成“靠近 → 停住观察 → 远离”。每次只提示一个动作；引导中的运动单程进行，反向动作在静止观察后解锁。键盘方向键、Home/End、精细位置轨道和点按移动提供等价操作方式。静止观察必须在靠近位等到指针归零并持续约 1.5 秒，中途离开或重新移动会重新计时；中途停住也会真实地归零，不会播放预设脉冲。

- 位置、磁通量、`e = -ΔΦ/Δt`、感应响应、阻尼指针及曲线由同一无量纲模型驱动。磁铁不穿过线圈中心，装置没有电池。
- 三时刻先比较有无响应与方向，如实保留各次实际运动用时；不会把不同速度的手动轨迹冒充严格定量对照。
- 可继续沿同一路径比较快慢。只有完整路径、明显不同的运动用时，以及相应的响应差异才闭合速度调查。相近或不充分的结果不会发放结论，会保留轨迹并用新基准继续，不必重做前三步。
- 示范、磁通示意不增加证据；点按辅助是用户发起的实际操作，使用同一模型与记录条件。隐藏页面或装置离屏时暂停运行。
- 三条观察后可先进入证据密室，之后打开磁铁实验会保留记录、直接继续速度步骤。速度对照为扩展实验，不强制阻挡密室主线。
- `?lab=magnet` 可独立试玩本关；独立进入不会凭空获得上一关的证据。

模型在 `lib/magnet-model.ts`，交互在 `components/magnet-discovery.tsx`；几何生成和审计在 `scripts/magnet-art/`，复用已有 MIT 绘图工具，不新增运行时依赖。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 检查与构建

```bash
npm run check
```

其中 `npm test` 验证稳态零信号、通断与极性反向、磁通量与感应电动势的一致性，以及证据闭合条件。GitHub Pages 发布流程会执行这些检查。

推送到 `main` 分支后，GitHub Actions 会构建静态版本并发布到 GitHub Pages。首次发布时需要在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 设计目标

结论不是章节的终点。Demo 更看重五种可迁移的科学能力：精确观察、控制变量、重复检验、排除替代解释，以及知道模型的适用边界。
